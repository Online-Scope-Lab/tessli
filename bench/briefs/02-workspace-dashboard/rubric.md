# Reviewer notes: workspace dashboard

- **Task fit:** could Maya tell in a few seconds what to do first today? The rejected drafts and the Thursday deadline should be impossible to miss.
- **Hierarchy and density:** is urgent work above routine status and activity? Is the project list easy to scan and compare (aligned figures, consistent columns or rows)?
- **Discoverability:** is it clear how to open each rejected draft or project?
- **Restraint:** count invented metrics, charts or numbers not in the brief against it.
- **Mobile usability:** at 390 px, is the order still "what needs action" first, and is the navigation reachable?
- **States:** are first use, no active projects, loading and error each distinct, with an appropriate message and action?
