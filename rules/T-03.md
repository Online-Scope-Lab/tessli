---
id: T-03
category: typography
title: Tabular figures for compared numbers
statement: Set prices, counts and numeric columns in tabular figures.
why: >-
  Proportional digits have different widths, so columns of numbers don't line
  up and values jitter when they update. Tabular figures keep every digit the
  same width.
check: "Inspect prices, counts and numeric columns: font-variant-numeric is tabular-nums."
anti_pattern: >-
  Prices and table totals in proportional figures, so columns zig-zag and a
  live counter shifts as it changes.
