---
id: A-02
category: accessibility
title: Visible focus
statement: Show a visible :focus-visible indicator on every interactive element.
why: >-
  Keyboard users need to see where they are. Removing the outline without a
  replacement leaves them navigating blind.
check: "Tab through at 1440 and 390: each stop shows an uncovered indicator at 3:1 contrast."
anti_pattern: >-
  outline: none in a global reset with no replacement, or a focus style that
  is only a faint colour change.
status: draft
reviewed_by: []
reviewed_at: null
sources:
  - WCAG 2.2 SC 2.4.7 Focus Visible (AA)
  - WCAG 2.2 SC 2.4.11 Focus Not Obscured (Minimum) (AA)
  - WCAG 2.2 SC 1.4.11 Non-text Contrast (AA)
---
