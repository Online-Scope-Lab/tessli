---
id: A-03
category: accessibility
title: AA contrast in every theme
statement: Meet 4.5:1 for text and 3:1 for large text and control edges, in every theme.
why: >-
  Muted grey on tinted surfaces is where contrast usually slips, and a pair
  that passes in the light theme can fail in the dark one. Checking every
  theme catches both.
check: "Run axe with the WCAG 2.2 AA tags in each theme: no contrast violations."
anti_pattern: >-
  Light-grey helper text on an off-white card, or muted text that passes only
  on pure white.
status: draft

reviewed_at: null
sources:
  - WCAG 2.2 SC 1.4.3 Contrast (Minimum) (AA)
  - WCAG 2.2 SC 1.4.11 Non-text Contrast (AA)
  - "docs/quality-gates.md (Accessibility: contrast)"
