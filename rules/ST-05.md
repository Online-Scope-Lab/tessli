---
id: ST-05
category: states
title: Destructive actions state consequences
statement: Before a destructive action, name what is lost and if it can be undone; confirm it.
why: >-
  Deletion is the one action people can't take back. Naming the object and the
  consequence turns an accidental click into a decision.
check: Each delete or reset confirms with the object and consequence named; Cancel gets focus.
anti_pattern: >-
  A red Delete button that acts at once, or an "Are you sure?" dialog with OK
  and Cancel and no word about what will be lost.

  - WAI-ARIA Authoring Practices Guide, Dialog (Modal) pattern
