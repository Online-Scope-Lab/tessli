---
id: K-03
category: components
title: Compared options share rows
statement: Give compared options the same rows in the same order, aligned, values written out.
why: >-
  Comparison happens row by row. When each option lists different features in
  a different order, people have to rebuild the table in their heads.
check: At 768 and up, each attribute lines up across options; values are text, not ticks.
anti_pattern: >-
  Pricing cards with a dozen ticked features each, mostly repeated, in a
  different order per card and out of line.
