---
id: T-02
category: typography
title: Few sizes, from one scale
statement: Take font sizes from the type scale; use at most four sizes in one section.
why: >-
  Hierarchy reads clearly when each size step means something. One-off sizes
  blur the steps and drift apart between components.
check: "List computed font sizes per section at 1440 and 390: all on the scale, four at most."
anti_pattern: >-
  Arbitrary values such as text-[15px] and text-[13.5px] chosen per component,
  with five or six sizes competing in one card.
status: draft
reviewed_by: []
reviewed_at: null
sources:
  - design.md §5 (type scale)
  - "Review dimension: consistency (docs/quality-gates.md)"
---

The limit of four sizes per section is a curator choice, not a number from design.md §5, which defines the scale but sets no count. A maintainer should confirm or change it when signing this rule.
