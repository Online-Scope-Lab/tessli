---
id: K-02
category: components
title: Links go, buttons do
statement: Use a link to go to a URL and a button to act on the page; the style never decides.
why: >-
  Links open in new tabs, can be copied and are announced as links; buttons
  submit and toggle. Using the wrong element breaks those expectations even
  when it looks right.
check: Everything that navigates has an href and works with middle click; buttons only act.
anti_pattern: >-
  A button that calls router.push() to navigate, or an anchor with href="#"
  that submits a form.
status: draft

  - WCAG 2.2 SC 4.1.2 Name, Role, Value (A)
